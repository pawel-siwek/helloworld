# Hello World

**Status: implemented.** The page is built with plain HTML and CSS; there is no
build step, JavaScript, backend, or dependency to install.

A minimal static page that displays `Hello World`.

## Open locally

Open `index.html` in a browser. The page and its stylesheet are local, so this
works offline.

## Optional: use a static server

You can serve the project directory with any static server you already have.
No particular server or command-line tool is required. Keep `index.html` and
`styles.css` together; the relative stylesheet URL also works when the site is
served from a subpath. For hosting, publish those two files to any static
hosting provider; this project does not configure or deploy hosting.

## Scope and browser targets

The page's only visible text is `Hello World`. Its targets are the latest stable
Chrome, Firefox, Safari, and Edge on desktop, Chrome on Android, and Safari on
iOS. These targets are not a claim that every browser or device has been
tested. Refer to [SPEC.md](SPEC.md) for requirements, acceptance criteria, and
scope.
